View SDK integration guides
Before you start, keep these tips in mind:
1
Use the Easy Monetization integration guides

Use the Easy Monetization guides — not the standard Yandex Advertising Network instructions.
2
Use the correct SDK build

Connect the unified mediation build:
YandexMobileAdsMediation.

If you’re using the full build, make sure the Easy Monetization mediation SDK dependency is included in your build.gradle, SPM, or UPM configuration.
3
Check for dependency conflicts

If you see errors about conflicting classes or dependencies, check whether the project contains incompatible ad SDKs or adapters.
4
Check the project configuration

•  Android: Check your AndroidManifest.xml, including the Google App ID if it is available in the Partner Interface.

•  iOS: Check your Info.plist.

•  Unity: Check AdapterInfo
5
Use the active ad unit IDs

Use only the active IDs shown in the Partner Interface. Please don’t use demo IDs, old IDs, or IDs from another mediation platform.
6
Update app-ads.txt

Add the latest app-ads.txt file to the website specified in the Partner Interface.
7
Test the integration before release

Please make sure that:

•  The SDK initializes correctly.

•  Ad requests are being sent.

•  There are no integration errors in the logs.
Once you’ve completed the integration, let me know and I’ll help you check that everything is working correctly before you release your app.
If anything is unclear or you run into an issue, simply reply to this email with a description of what happened or the relevant logs. I’ll help you resolve it and guide you through the remaining steps.
